# 🌐 Network Traffic Anomaly Detection using Isolation Forest

Built an unsupervised machine learning project using a Network Traffic dataset to detect unusual or suspicious behavior in network activity. The Isolation Forest algorithm was used to identify anomalies automatically from high-dimensional traffic data.

---

## Objective

To detect abnormal network traffic patterns and identify potential suspicious activities using anomaly detection techniques.

---

## Approach

### 🔹 Data Preprocessing

* Loaded and cleaned the dataset
* Removed missing values
* Selected numerical features
* Applied feature scaling using StandardScaler

### 🔹 Model Development

Implemented:

* Isolation Forest Algorithm
* PCA for dimensionality reduction

Generated:

* Anomaly Predictions
* PCA-based Visualizations

---

## Evaluation & Analysis

* Anomaly Count Analysis
* Anomaly Percentage Calculation
* Pattern Visualization using PCA

---

## Visualizations

* PCA Scatter Plot for Anomaly Detection
* Feature Correlation Heatmap
* Feature Distribution Histograms

---

## Key Results

* Detected abnormal network traffic patterns
* Identified isolated anomalous data points
* Visualized anomalies using PCA
* Generated a final dataset with anomaly labels
* Demonstrated a real-world cybersecurity use case
