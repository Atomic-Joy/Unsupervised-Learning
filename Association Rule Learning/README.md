# 🛒 Online Retail Market Basket Analysis using Apriori

Built an unsupervised machine learning project using the Online Retail dataset to discover products frequently purchased together. The Apriori algorithm was used to generate frequent itemsets and association rules from transactional data.

---

## Objective

To identify relationships between products and analyze customer buying patterns using association rule learning.

---

## Approach

### 🔹 Data Preprocessing

* Removed missing values
* Filtered invalid transactions
* Converted data into basket format
* Transformed data into boolean format

### 🔹 Model Development

Implemented:

* Apriori Algorithm
* Association Rule Mining

Generated:

* Frequent Itemsets
* Association Rules

---

## Evaluation Metrics

* Support
* Confidence
* Lift

---

## Visualizations

* Top Association Rules by Lift
* Support vs Confidence Scatter Plot
* Lift Distribution Histogram

---

## Key Results

* Identified products frequently purchased together
* Generated meaningful association rules
* Analyzed customer buying behavior patterns
* Visualized product relationships using plots
